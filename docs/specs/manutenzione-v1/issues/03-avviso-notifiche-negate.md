# 03: Avviso se le notifiche sono negate

**What to build:** se le notifiche dell'app sono disattivate (permesso negato su Android 13+ o disattivate dalle impostazioni di sistema), la schermata principale mostra un avviso e un pulsante che apre le impostazioni notifiche dell'app. Tornando nell'app dopo averle riattivate, l'avviso scompare.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Notifiche disattivate → avviso e pulsante visibili
- [ ] Il pulsante apre le impostazioni notifiche di questa app
- [ ] Riattivate le notifiche e tornati nell'app → avviso nascosto senza riavviare l'app
- [ ] Notifiche attive → nessun avviso
